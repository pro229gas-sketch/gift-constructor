# 🎃 Halloween Spooky Gift Generator

Навчальний вебпроєкт — конструктор хелловінських подарунків. Користувач обирає **отримувача**, **подію** та **бюджет**, а застосунок за мить формує **три варіанти подарункових боксів** (коробка + набір солодощів і сувенірів), сума яких не перевищує вказаний бюджет. Окрема **адмін-панель** дозволяє змінювати всі довідники та ціни без редагування коду.

> Це демонстраційний проєкт: назви й ціни умовні, замовлення не оформлюються, сервер не використовується.

## Головні можливості

**Для користувача (`index.html`)**

- Конструктор із трьох полів: отримувач (8 варіантів), подія (5 варіантів), бюджет у гривнях.
- Валідація форми засобами HTML5 + CSS (`required`, `min`, `max`, `step`) без додаткового JavaScript.
- Генерація **трьох карток-боксів** поруч, кожна з яких містить:
  - тематичну назву, що залежить від отримувача;
  - назву варіанта (Класичний / Затишний / Таємничий);
  - вибрану коробку та до 4 випадкових товарів, що вміщаються в бюджет;
  - загальну вартість, шкалу використання бюджету та залишок;
  - підказку з описом, для кого й на яку подію зібрано набір.
- Кнопка **«Згенерувати інші бокси»** — перемішує склад.
- Кнопка **«Скопіювати список»** — копіює склад боксу в буфер обміну.
- Автоматичне **збереження й відновлення** останніх введених значень форми.
- Розділи «Як це працює» та «Часті запитання» (`<details>`), липка шапка, посилання «Перейти до конструктора» (skip-link) та ARIA-атрибути для доступності.

**Для адміністратора (`admin.html`)**

- Вхід за паролем (демо-пароль: `admin123`).
- Керування списками **отримувачів** і **подій**: додавання, редагування, видалення.
- Керування **товарами** і **коробками**: іконка, назва, ціна (швидка зміна ціни прямо в списку, повне редагування рядка).
- Налаштування **мінімального та максимального бюджету**.
- Кнопка **«Скинути до початкових»** — повертає стандартні значення.
- Зміни одразу діють на головній сторінці (через `localStorage`).

## Структура проєкту

Проєкт плоский, без збірки та залежностей — усі файли лежать в одній директорії:

```
spooky-gifts/
├── index.html    # Головна сторінка: конструктор, результати, інструкція, FAQ
├── app.js        # Логіка генерації боксів + підхоплення налаштувань адміна
├── admin.html    # Сторінка адмін-панелі
├── admin.js      # Логіка адмін-панелі: авторизація, CRUD, збереження
├── styles.css    # Спільні стилі (тема, форми, картки, адмін-панель)
└── README.md     # Цей файл
```

| Файл | Призначення |
|------|-------------|
| `index.html` | Розмітка публічної частини: шапка, hero-блок, форма, контейнер результатів `#results`, секції `#how` і `#faq`, футер. |
| `app.js` | Дані за замовчуванням (`SPOOKY_ITEMS`, `SPOOKY_BOXES`), побудова та рендер карток, копіювання, збереження форми; в кінці файлу — блок, що підтягує дані адміна. |
| `admin.html` | Розмітка форми входу та панелі керування; додаткові стилі й кастомний скролбар підключені всередині `<style>`. |
| `admin.js` | Початкові дані (`defaults`), завантаження/збереження, рендер списків, режим редагування, валідація, вхід/вихід. |
| `styles.css` | Єдиний файл стилів для обох сторінок (CSS-змінні теми, на кшталт `--pumpkin-glow`, `--panel-border`, `--text-muted`). |

## Компоненти та модулі

### `app.js`

| Елемент | Опис |
|---------|------|
| `SPOOKY_ITEMS` | Каталог товарів `{ name, price, icon }` (11 позицій за замовчуванням). |
| `SPOOKY_BOXES` | Каталог коробок `{ name, price, icon }` (3 позиції за замовчуванням). |
| `readForm / saveForm / restoreForm` | Читання, збереження в `localStorage` і відновлення значень форми. |
| `shuffle(list)` | Перемішування масиву (алгоритм Фішера — Йєтса). |
| `buildSpookyComposition(...)` | Формує склад боксу: віднімає ціну коробки від бюджету й випадково додає до 4 товарів, що вміщаються. |
| `renderResults / renderCard` | Вибирає 3 випадкові коробки та рендерить картки. |
| `escapeHtml` | Екранування користувацьких/збережених рядків перед вставкою в HTML. |
| `copyCard` | Копіювання списку складу через `navigator.clipboard`. |
| IIFE «Load settings…» | Читає `spookyAdminData`, оновлює випадні списки, каталоги та межі бюджету (атрибути `min`/`max`, підказка й текст помилки). |

### `admin.js`

| Елемент | Опис |
|---------|------|
| `defaults` | Початкові значення: отримувачі, події, товари, коробки, `min = 300`, `max = 100000`. |
| `load / save` | Завантаження з `localStorage` з перевіркою структури та збереження. |
| `renderOptionList` | Список отримувачів/подій (`value` + `label`) з редагуванням і видаленням. |
| `renderCatalog` | Список товарів/коробок (іконка, назва, ціна) з редагуванням і видаленням. |
| `addOption / addCatalog` | Додавання нових елементів із валідацією (унікальність, ціна ≥ 10 ₴). |
| `setAuth / login` | Вхід/вихід; стан сесії зберігається в `sessionStorage`. |
| Режим редагування | `Enter` — зберегти, `Esc` — скасувати. |

### Правила та обмеження адмін-панелі

- Отримувачів, подій і товарів має лишатися **щонайменше 1**.
- Коробок має лишатися **щонайменше 3** (`MIN_BOXES`), бо на сторінці показуються три варіанти.
- Ціна — ціле число **від 10 ₴**.
- Максимальний бюджет має бути **більшим** за мінімальний.
- Значення отримувачів/подій не повинні дублюватися (без урахування регістру).

## Системні вимоги

- Сучасний браузер із підтримкою ES2015+, `localStorage`, `sessionStorage`, `form.requestSubmit()` та Clipboard API:
  - Chrome / Edge 90+
  - Firefox 90+
  - Safari 14+
- Для роботи копіювання в буфер обміну потрібен безпечний контекст (`https://` або `http://localhost`).
- **Збірка, Node.js, npm та бекенд не потрібні.**
- Опційно (для локального сервера): Python 3 **або** Node.js 16+.

## Запуск

### Варіант 1 — відкрити файл напряму

Двічі клацніть `index.html` або перетягніть його у вікно браузера.

> ⚠️ Деякі браузери по-різному ізолюють `localStorage` для сторінок із `file://`. Якщо зміни з адмін-панелі не з'являються на головній сторінці, скористайтеся локальним сервером.

### Варіант 2 — локальний сервер (рекомендовано)

**Python:**

```bash
python3 -m http.server 8000
```

**Node.js:**

```bash
npx serve .
```

Після цього відкрийте:

- Головна сторінка: <http://localhost:8000/index.html>
- Адмін-панель: <http://localhost:8000/admin.html>

(Для `npx serve` порт буде показано в консолі.)

## Сценарії використання

### 1. Підібрати подарунок

1. Відкрийте `index.html`.
2. Оберіть **отримувача** (наприклад, «Відьмочка / Чаклунка») і **подію** (наприклад, «Відьомський Шабаш»).
3. Вкажіть **бюджет** — наприклад, `1000` (мінімум 300 ₴, крок 10 ₴).
4. Натисніть **«Згенерувати Хелловінські Бокси 🎃»**.
5. Порівняйте три картки: вартість, залишок бюджету, склад.

### 2. Отримати інші варіанти

Натисніть **«🔄 Згенерувати інші бокси»** під результатами — коробки й товари будуть підібрані заново.

### 3. Скопіювати склад

На потрібній картці натисніть **«📋 Скопіювати список»**. У буфер потрапить текст такого вигляду:

```
Чаклунський Бокс «Зілля & Чари» 🧙‍♀️ (Класичний)
- Чорний Гарбузовий Бокс із кажанами — 150 ₴
- Цукрова вата "Павутиння Жаху" — 140 ₴
- ...
Разом: 920 ₴
```

### 4. Змінити довідники та ціни (адмін)

1. Відкрийте `admin.html` (або натисніть «🔐 Адмін-панель» у шапці).
2. Введіть пароль `admin123` і натисніть **«Увійти»**.
3. Скористайтеся потрібним блоком:
   - **Отримувачі / Події** — введіть назву й натисніть «Додати»; ✏️ — редагувати, ✕ — видалити.
   - **Товари / Коробки** — вкажіть іконку, назву, ціну; ціну можна змінити прямо в рядку.
   - **Ліміти бюджету** — задайте мінімум і максимум, натисніть «Зберегти ліміти».
4. Поверніться на головну (`← На головну`) і оновіть сторінку — нові дані вже застосовано.

### 5. Скинути налаштування

В адмін-панелі натисніть **«Скинути до початкових»**. Кнопка **«Вийти»** завершує сесію адміністратора.

## Зберігання даних

| Ключ | Сховище | Вміст |
|------|---------|-------|
| `spookyGiftForm` | `localStorage` | Останні значення форми (отримувач, подія, бюджет). |

## Обмеження та примітки

- **Пароль адміністратора (`admin123`) прописаний у клієнтському коді** і слугує лише для демонстрації — це не справжня автентифікація. Не використовуйте такий підхід у production.
- Дані зберігаються лише в браузері конкретного користувача; між пристроями вони не синхронізуються.
- Заголовки боксів заздалегідь визначені для 8 початкових отримувачів. Для нових отримувачів, доданих в адмін-панелі, використовується універсальна назва «Хелловінський Подарунковий Бокс 🎃».
- Якщо знизити мінімальний бюджет нижче суми «найдешевша коробка + найдешевший товар», окремі бокси можуть вийти без товарів або з меншою кількістю позицій.
- Склад боксу випадковий (до 4 товарів), тому сума може бути меншою за бюджет — залишок показується на картці.
